# Screenshots

Promotional / documentation captures referenced from the project
`README.md` and the PyPI long-description.

## Conventions

- PNG, captured at terminal size ≥ 160×40 in `xterm-kitty` (so inline
  images and themes render at full fidelity).
- Filename describes the view: `library.png`, `reader-scroll.png`,
  `reader-paged.png`, `theme-picker.png`, `bookmarks.png`.
- Keep file size reasonable (<500 KB per shot); use a recent screen
  capture tool rather than re-encoding existing JPEGs.
- Update the relevant README image link when adding/replacing a shot.
